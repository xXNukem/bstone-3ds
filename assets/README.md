# Homebrew Launcher icon

Original BS pixel-grid insignia for Blake Stone 3DS, authored as geometry in
`tools/create_launcher_icon.py` (MIT). No original commercial game artwork,
third-party images or generative-AI artwork is used. The checked-in 48×48 PNG
feeds smdhtool; the 24×24 nearest-neighbor variant is available for its small icon.
Regeneration uses only Python's standard library and is NOT a build requirement.
Game/source credits remain in README, LICENSE.txt, README_UPSTREAM.md and licenses/.
Homebrew port author: Carlos de la Barrera Perez.
